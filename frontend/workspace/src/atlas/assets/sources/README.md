# Search-source marks

These unmodified official assets identify the sources queried by MolAgent. Marks remain the property of their respective owners.

- `openalex.png`: OurResearch / OpenAlex, [official website repository](https://github.com/ourresearch/openalex-website/blob/master/public/favicon.png).
- `arxiv.png`: arXiv, [official website icon](https://github.com/arXiv/arxiv-base/blob/develop/arxiv/base/static/images/icons/favicon-32x32.png). Used to acknowledge arXiv API data under the [brand guidelines](https://github.com/arXiv/arxiv-docs/blob/develop/source/brand/brand-guidelines.md). The acknowledgement appears in the expanded arXiv results.
- `europepmc.png`: Europe PMC / EMBL-EBI, [official technical blog repository](https://github.com/EuropePMC/techblog/blob/gh-pages/images/epmc-logo.png). Europe PMC outreach material is [CC BY-SA 4.0](https://europepmc.org/Outreach); the logo retains its original transparent background.
- `pubchem.svg`: NCBI / NLM, [official PubChem website logo](https://pubchem.ncbi.nlm.nih.gov/pcfe/logo/PubChem_logo.svg).
- `rdkit.png`: RDKit contributors, [official RDKit website logo](https://www.rdkit.org/Images/logo.png). Used to identify the toolkit performing structure checks and molecular generation.
