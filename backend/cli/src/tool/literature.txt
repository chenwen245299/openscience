Find and read scholarly papers.

search: one query across OpenAlex and arXiv (override with `sources`). Returns deduplicated candidates with title, authors, year, venue, DOI / arXiv id, citations, abstract, landing URL and whether open full text is reachable, plus which source answered, fell back, or failed. Prefer two or three targeted queries to one broad one.

read: `ref` is a DOI, arXiv id, URL, local PDF path, or exact title. Resolves the open full text, downloads it once into the session's paper cache, extracts page-addressed text and returns the opening pages, a `pages` range, or passages matching `query`. Says plainly when only the abstract is available or the text is partial. Read the closest papers before citing them; a snippet is not a reading.

Molecular run body reading: call {"action":"read","run":"<run directory>","source":"<retained paper DOI or arXiv id>"}. The run contains evidence_pack.json; source must identify one of its retained papers (an exact title also works). This fixed interface resolves Europe PMC article-body XML, arXiv HTML/PDF and open-access copies, extracts section/page-addressed body blocks, saves the complete evidence under <run>/literature/ and updates that paper's full_text record automatically. It returns stable block indices for Findings citations. Cached bodies are reused. Do not discover endpoints, write download scripts, or manually patch the evidence pack. Add query to read matching sections/passages, or pages for a PDF range. For a supplied local PDF, add ref:"/path/to/paper.pdf" with the same run and source. Unavailable bodies stay explicitly unavailable; an abstract or landing page never counts as a body read. Retrieval does not synthesize Findings or mark the paper reviewed: read the body and write your supported design interpretation through the skill's review contract.

Web pages go through webfetch; database records by accession go through the scientific database tools when a skill offers them.
